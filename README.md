# tvv-pr0-parallel-primes

Практическая работа № 0 по дисциплине «Технология высокопроизводительных вычислений» (РТУ МИРЭА):
сравнение последовательной и многопроцессной обработки списка значений на Kotlin.

Для каждого из N значений (случайные числа из диапазона [250 000; 500 000], seed = 42) вычисляется количество простых
чисел, не превосходящих значение (решето Эратосфена). Параллельный режим запускает p отдельных JVM-процессов,
каждый из которых обрабатывает свой непрерывный диапазон списка. Время параллельного замера включает запуск процессов.

## Требования

- JDK 21
- Gradle берётся из wrapper (`./gradlew`), отдельная установка не нужна
- Python 3 и `matplotlib` только для построения графика

## Запуск

```bash
./gradlew installDist
build/install/tvv-pr0-parallel-primes/bin/tvv-pr0-parallel-primes bench
```

Либо одной командой: `./gradlew run --args="bench"`.

Режим `bench` для N = 1 000, 5 000, 20 000 и p = 1, 2, 4, 8 делает по 3 замера, берёт медиану, сверяет контрольные суммы
с последовательным результатом и записывает `results/results.csv`. Необязательные аргументы: `bench [maxValue] [csv]`.

График ускорения: `pip install matplotlib && python3 plot.py` (создаёт `results/speedup.png`).

## Результаты

`results/results.csv`: режим (`sequential` или `parallel`), N, число процессов, медиана времени и все три замера в секундах,
ускорение относительно одного процесса `T(1) / T(p)`, контрольная сумма. Замеры в репозитории получены на MacBook
с Apple M3 (4 производительных + 4 энергоэффективных ядра, 16 ГБ RAM).
